# STI筛查与检测指南

> 数据来源：CDC 2024筛查建议 + WHO 2021治疗方案
> 更新时间：2026-08-19

---

## 📅 常规筛查建议

### 女性

| 疾病 | 筛查年龄/人群 | 频率 |
|------|-------------|------|
| 衣原体 | 25岁以下性活跃女性 | 每年一次 |
| 衣原体 | 25岁以上高风险 | 每年一次 |
| 淋病 | 25岁以下性活跃女性 | 每年一次 |
| 淋病 | 25岁以上高风险 | 每年一次 |
| HIV | 13-64岁所有人 | 至少一次（opt-out） |
| HIV | 高风险人群 | 每3-6个月 |
| 梅毒 | 孕妇首次产检 | 一次 |
| 梅毒 | 高风险孕妇 | 孕晚期+分娩时 |
| HPV/宫颈癌 | 21-29岁 | 细胞学每3年 |
| HPV/宫颈癌 | 30-65岁 | 细胞学+HPV每5年 |

### 男性

| 疾病 | 筛查人群 | 频率 |
|------|---------|------|
| HIV | 所有性活跃男性 | 至少一次 |
| HIV | MSM(男男性行为者) | 每3-6个月 |
| 梅毒 | MSM | 每年一次 |
| 衣原体/淋病 | MSM（尿道/直肠/咽部）| 每年一次 |
| 乙肝 | 未接种者 | 一次检测 |

### 孕妇

- 首次产检：HIV、梅毒、乙肝、丙肝、衣原体、淋病
- 孕晚期（28-32周）：高风险孕妇复查HIV/梅毒
- 分娩时：未筛查孕妇快速检测HIV

## 🔬 症状识别

### 尿道综合征（ urethral discharge syndrome）

**症状**：
- 尿道分泌物（白色/黄色/绿色）
- 排尿疼痛或灼热感
- 尿道瘙痒

**常见病原体**：
- 淋病奈瑟菌（淋病）
- 沙眼衣原体
- 生殖支原体

**检测**：
- 尿液NAAT（首选）
- 尿道分泌物涂片+培养

### 阴道 discharge 综合征

**症状**：
- 阴道分泌物异常（量/颜色/气味）
- 外阴瘙痒/刺激
- 性交疼痛

**常见病原体**：
- 滴虫（trichomonas）
- 细菌性阴道病（BV）
- 念珠菌（真菌）
- 衣原体/淋病

**检测**：
- 阴道分泌物pH值
- 湿片显微镜检查
- NAAT检测衣原体/淋病/滴虫

### 生殖器溃疡综合征

**症状**：
- 生殖器/肛门周围溃疡或水疱
- 疼痛或无痛性溃疡
- 腹股沟淋巴结肿大

**常见病原体**：
- 梅毒（硬下疳，通常无痛）
- 生殖器疱疹（HSV，疼痛性水疱）
- 软下疳（ Haemophilus ducreyi）
- 性病淋巴肉芽肿（LGV）

**检测**：
- 溃疡分泌物PCR（HSV）
- 血清学检测（梅毒、HIV）
- 培养（软下疳）

### 下腹痛综合征

**症状**：
- 下腹部疼痛
- 异常阴道出血
- 发热
- 性交疼痛

**常见原因**：
- 盆腔炎病（PID）— 衣原体/淋病上行感染
- 异位妊娠
- 卵巢囊肿扭转

**检测**：
- 妊娠测试
- 盆腔超声
- 宫颈拭子NAAT

## 🏥 检测地点与方式

### 医疗机构

- **社区卫生服务中心**：免费或低价STI检测
- **医院皮肤性病科**：专业检测+治疗
- **计划生育门诊**：避孕+STI筛查一站式

### 自我采样

- **尿液NAAT**：可自行留取首段尿
- **阴道拭子**：部分国家允许自采
- **指尖血**：HIV/梅毒快速检测

### 居家检测包

- 美国：Everlywell、LetsGetChecked
- 中国：部分互联网医院提供检测包邮寄

---

## ⏱️ 检测时机

| 感染 | 窗口期（检测时间） |
|------|------------------|
| 衣原体 | 1-2周后NAAT可检出 |
| 淋病 | 1-2周后NAAT可检出 |
| 梅毒 | 3-6周后血清学阳性 |
| HIV | 4代检测：2-6周；RNA检测：10-14天 |
| HSV | 溃疡出现后PCR最准；血清学需6-12周 |
| HPV | 无常规血液检测，靠细胞学/HPV分型 |
| 滴虫 | 1-2周后检测 |

**建议**：高危行为后2周做首次检测，3个月复查确认。

---

## 🚫 高危行为定义

以下情况建议更频繁筛查：

- 有多个性伴侣
- 新性伴侣未检测
- 无保护性行为
- 性伴侣有STI
- MSM群体
- 注射吸毒者
- 酒吧/夜店从业者
- 既往有STI史

---

## 💊 治疗后复查

- **衣原体/淋病**：治疗后3个月复查（再感染率高）
- **梅毒**：治疗后3、6、12个月血清滴度监测
- **HIV**：确诊后定期CD4+病毒载量监测
- **疱疹**：无需常规复查，症状复发时就诊

---

## 📞 中国检测资源

- **各地疾控中心(VCT门诊)**：免费咨询检测
- **医院皮肤性病科**：正规检测+治疗
- **互联网医院**：部分提供检测包邮寄服务

**重要提醒**：STI可治愈≠可忽视，定期筛查是负责任的表现。
